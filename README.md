# Exercism | Jornada Prática em Java

Este espaço é dedicado a documentar a minha evolução prática na linguagem **Java** através da plataforma **Exercism**. 

Aqui, coloco a teoria em prática resolvendo desafios de código que cobrem desde os fundamentos da linguagem até conceitos avançados de engenharia de software. Cada diretório e exercício reflete um passo a mais no domínio de boas práticas, resolução de problemas e estruturação de código limpo (*Clean Code*).

## 🎯 O que você encontra por aqui:
* **Estruturas de Dados e Algoritmos:** Manipulação eficiente de arrays, listas, mapas e coleções.
* **Paradigma Orientado a Objetos:** Aplicação de encapsulamento, herança, polimorfismo, interfaces e tipos genéricos (*Generics*).
* **Resiliência e Tratamento de Erros:** Implementação de validações defensivas, lançamento e captura de exceções.
* **Qualidade de Código:** Código estruturado, testes unitários automatizados e foco em legibilidade.

Sinta-se à vontade para explorar os códigos, acompanhar meu progresso e trocar ideias sobre as soluções! 🚀☕
